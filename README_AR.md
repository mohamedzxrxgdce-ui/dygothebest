# dygothebest

مشروع Expo / React Native كبداية عملية لتطبيق أنمي عربي.

## الموجود حالياً
- واجهة عربية داكنة.
- عرض أنميات شائعة والبحث عنها عبر Jikan API.
- صفحة تفاصيل الأنمي.
- قائمة مفضلة (مؤقتة أثناء تشغيل التطبيق).
- مشغل مبني على `expo-video`.
- زر CC كواجهة أولية.

## مهم قبل اعتبار التطبيق مكتملاً
هذا المشروع **ليس منصة بث جاهزة**: Jikan يوفر معلومات الأنمي ولا يوفر روابط تشغيل الحلقات. يلزم اختيار مزود قانوني وموثوق للفيديو والترجمة، أو استخدام روابط تملك حق استخدامها. لا توجد حلقات محمية أو روابط بث مضمّنة في هذا ZIP. زر CC موجود، لكن ربط ملفات الترجمة الفعلية يحتاج مصدر ترجمة متوافقاً مع مصدر الفيديو.

## التشغيل
يتطلب Node.js 20 أو أحدث:
```bash
npm install
npx expo start
```

## بناء APK سحابياً
1. أنشئ حساب Expo واربط المشروع باستخدام `npx eas-cli build:configure`.
2. ثبّت EAS CLI: `npm install -g eas-cli`.
3. سجّل الدخول: `eas login`.
4. نفّذ بناء APK تجريبي: `eas build --platform android --profile preview`.
5. تابع البناء في لوحة Expo EAS ونزّل APK عند اكتماله.

GitHub وحده لا يبني APK تلقائياً من دون إعداد حساب/اعتمادات بناء. ملف `validate.yml` الحالي يفحص تثبيت المشروع وExpo Doctor فقط، ولا يدّعي إنتاج APK.

## ملاحظات
- بيانات الأنمي تأتي من Jikan API (خدمة خارجية؛ قد تفرض حدود طلبات أو تتوقف مؤقتاً).
- لا تضع مفاتيح سرية أو كلمات مرور داخل ملفات المشروع.
- يلزم اختبار التطبيق على جهاز Android فعلي قبل النشر.
